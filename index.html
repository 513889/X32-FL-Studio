3FL 混音台：路由防護設定 (防嘯叫)

按下 F9 開啟混音台。為防止麥克風聲音從筆電喇叭竄出造成嘯叫，請針對 Insert 1~5 軌，【擇一】執行以下防護：

  • 作法 A (靜音模式)： 將 Insert 軌上方的 🟢 綠色小圓燈點暗 (喇叭不出聲，不影響錄音寫入硬碟)。
  • 作法 B (斷開路由)： 點選 Insert 軌後，視線移至 M (Master) 軌下方，點擊綠色箭頭斷開連線 ❌。

⚠️ 注意事項：C 軌與 M 軌的設定原則

  • C (Current) 動態監聽軌：請勿點亮紅燈！否則會將操作軟體時的軌道切換音一併錄入。
  • M (Master) 總輸出軌：請勿點亮紅燈！Insert 軌已在錄音，若 M 軌重複錄製，會產生疊音回授及系統雜音。

📌現場走帶操作 6 大要訣

  • 1. 存檔與模式：開場按 Ctrl + S 存檔。走帶區需設定為 SONG (歌曲模式)，避免使用 PAT 模式。
  • 2. 軌道設定 (防護與備戰)：確認 Insert 1~5 軌 🟢 綠燈暗 或 ❌ 點斷連線 (防嘯叫)，並確認 🔴 紅燈亮 (準備錄製)。
  • 3. 啟動錄音：點亮頂部 🔴 錄音鍵，請選取 "錄製音頻至播放清單..."，再按 ▶️ 播放鍵啟動。
  • 4. 檢視波形：開錄後，按鍵盤 F5 叫出播放清單，確認各軌波形是否正常繪製。
  • 5. 中場休息 (使用暫停)：短暫休息 僅按 ⏸️ 暫停鍵。請避免按 ⏹️ 停止鍵 (會使時間軸歸零)。下半場直接按 ▶️ 播放鍵繼續。
  • 6. 收工與試聽：全場結束才按 ⏹️ 停止鍵，並按 Ctrl + S 存檔。若需試聽，將 Insert 的 🟢 綠燈重新點亮 (或連回 M 軌)。

4正式啟動錄音作業

  1. 按下頂部面板的 🔴 錄音鍵 (Record Arm)。
  2. 【重要設定】 於選單選取 "錄製音頻至播放清單作為音頻剪輯"。
  3. 按下 ▶️ 播放鍵 (Play) 啟動時間軸，開始錄製。
  4. 按下鍵盤 F5 切換至「播放清單」，確認波形正常顯示。

5回放檢查與路由復原

一、 恢復聲音輸出

請依據步驟三選擇的作法，恢復音訊連線：

  • 若採 作法 A (綠燈點暗)：請將 5 軌的 🟢 綠燈重新點亮。
  • 若採 作法 B (物理斷開)：請將 5 條虛線 重新接回 M (Master) 軌。
  • ⚠️ 試聽前請將 5 軌的 🔴 紅燈點暗，以免誤錄。
二、 透過 X32 控台路由至現場喇叭
  1. X32 點選 Routing -> Inputs，將第一組改為 Card 1-8。
  2. 推起 CH1 與 CH2 推桿（接收電腦音源）及 Matrix 推桿（輸出至擴大機）。
  3. 點擊 FL Studio ▶️ 鍵開始回放。

6匯出標準音訊檔 (MP3 / WAV)

File ➔ Export ➔ MP3 file... (或 WAV file)
  1. 指定儲存路徑與命名。 Render 視窗維持預設，按 Start 產出 MP3。

⚙️ 【進階操作】匯出獨立分軌檔

在 Render 視窗右下角 Miscellaneous (雜項) 區塊，勾選 Split mixer tracks (分離混音軌道)，按 Start 即可產出各軌獨立的 WAV 音檔。

🚨實戰疑難排解 (進階狀況排除)

Q1: 領夾式電容麥克風的波形極小，X32 的 Gain 轉大還是偏小？

【硬體特性】波形偏小屬正常現象： 領夾麥克風音頭極小，且通常配戴於胸前（距離嘴巴較遠）。依聲學物理，實際進入控台的訊號本就會比手握麥克風微弱。此外，請確認 X32 該軌已開啟 +48V 幻象電源。
【配戴要領】唐裝與一般服飾的黃金位置： 避免夾在領口最高處（第一顆扣子），以免因「下巴陰影效應」造成聲音沉悶。理想距離為下巴往下約 15~20 公分 (一個手掌寬)。

Q2: 錄音進行中，可否直接拉 FL 混音台的推桿將聲音變大？

【軟體邏輯】調整無效： FL Studio 採用「推桿前 (Pre-Fader) 錄音」機制。訊號在經過軟體推桿前就已存入硬碟。錄音時移動推桿，僅會改變耳機內的監聽音量，實際錄製的波形大小不會改變。
👉 處置方式： 錄音當下若需放大音量，需調整 X32 控台上的硬體 Gain (增益) 旋鈕。

Q3: 錄完後波形偏小，如何平衡各軌音量，並確保匯出時不破音？

【混音訊號疊加原理】 軟體匯出之總輸出 (Master) 音量，是各音軌數值的 直接相加。若將多軌音量推至極限，匯出時容易產生削峰破音 (Clipping)。建議採行以下標準平衡流程：

👉 步驟一：音頻標準化 (Normalize)
於 F5 播放清單中，雙擊需放大的波形 ➔ 於屬性視窗點擊 Normalize (標準化)。
此功能會將該軌訊號無損放大至安全極限值。
👉 步驟二：拉降推桿 (混音平衡)
各軌音量放大後，請至 FL 混音台 將相關軌道的推桿適度往下拉降 (如降至 -10dB)。
藉此預留訊號相加的空間，確保整體匯出音質飽滿且無破音。
