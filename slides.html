3FL 混音台：路由防護設定 (防嘯叫)

按下 F9 開啟混音台。為防止麥克風聲音從筆電喇叭竄出造成嘯叫，請針對 Insert 1~5 軌，【擇一】執行以下防護：

  • 作法 A (靜音模式)： 將 Insert 軌上方的 🟢 綠色小圓燈點暗。
  • 作法 B (斷開路由)： 點選 Insert 軌後，視線移至 M (Master) 軌下方的「發光綠色箭頭」，點擊將其斷開 ❌。

📌現場走帶操作 6 大要訣

  • 1. 存檔與模式：開場按 Ctrl + S 存檔。走帶區需設定為 SONG (歌曲模式)，避免使用 PAT 模式。
  • 2. 軌道設定 (防護與備戰)：確認 Insert 1~5 軌 🟢 綠燈暗 或 ❌ 點斷連線，並確認 🔴 紅燈亮。
  • 3. 啟動錄音：點亮頂部 🔴 錄音鍵，請選取 "錄製音頻至播放清單..."，再按 ▶️ 播放鍵啟動。
  • 4. 檢視波形：開錄後，按鍵盤 F5 叫出播放清單，確認各軌波形是否正常繪製。
  • 5. 中場休息 (使用暫停)：短暫休息 僅按 ⏸️ 暫停鍵。勿按 ⏹️ 停止鍵(游標會歸零)。下半場按 ▶️ 接續。
  • 6. 收工與試聽：全場結束才按 ⏹️ 停止鍵。若需試聽，將 Insert 的 🟢 綠燈重新點亮 (或連回 M 軌)。

4正式啟動錄音作業

  1. 按下 🔴 錄音鍵 ➔ 於選單選取 "錄製音頻至播放清單作為音頻剪輯"。
  2. 按下 ▶️ 播放鍵 開始錄製。
  3. 按下鍵盤 F5 切換至「播放清單」確認波形顯示。

5回放檢查與路由復原

一、 恢復聲音輸出

  • 依據步驟三之作法：將 5 軌的 🟢 綠燈重新點亮，或是 重新接回 M (Master) 軌。
  • ⚠️ 試聽前請將 5 軌的 🔴 紅燈點暗，以免誤錄。

二、 透過 X32 控台路由至現場喇叭

  1. X32 點選 Routing -> Inputs，將第一組改為 Card 1-8。
  2. 推起 CH1 與 CH2 推桿（接收電腦音源）及 Matrix 推桿（輸出至擴大機）。
  3. 點擊 FL Studio ▶️ 鍵開始回放。

6匯出標準音訊檔 (MP3 / WAV)

File ➔ Export ➔ MP3 file... (或 WAV file) ➔ Start

【匯出獨立分軌檔】： 在 Render 視窗右下角 Miscellaneous (雜項) 區塊，勾選 Split mixer tracks (分離混音軌道)，按 Start 即可。

🚨操作疑難排解 (2/2)

Q2: 錄音進行中，可否直接拉 FL 混音台的推桿將聲音變大？

【調整無效】 軟體為「推桿前 (Pre-Fader) 錄音」。移動軟體推桿不改變寫入硬碟的波形大小。
👉 處置方式： 錄音當下若需放大音量，需調整 X32 控台上的實體 Gain (增益) 旋鈕。

Q3: 錄完後波形偏小，如何平衡各軌音量，並確保匯出時不破音？

【混音疊加原理】 總輸出 (Master) 音量是各音軌數值的 直接相加。建議採行以下標準平衡流程：

👉 步驟一：音頻標準化 (Normalize)
於 F5 播放清單中，雙擊需放大的波形 ➔ 於屬性視窗點擊 Normalize (標準化)。
此功能會將該軌訊號無損放大至安全極限值。
👉 步驟二：拉降推桿 (混音平衡)
各軌音量放大後，請至 FL 混音台 將相關軌道的推桿適度下拉 (如降至 -10dB)。
藉此預留訊號相加的空間，確保整體匯出無破音。
